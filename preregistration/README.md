# Preregistration record: SSRN 7099378

The paper "Survivorship Bias in Indian Equities Is Not a Number" (SSRN abstract id
7099378) states that its analyses follow a pre-registered pipeline. This folder is the
public evidence for that statement.

Contents:

- `P2_PREREG_LITE.md` - the preregistration text, verbatim, with the commit id and
  timestamp under which it entered the research repository.
- `RECEIPTS.md` - the git hash chain showing the design was committed before the first
  results, the verification command, and the same morning's hash-bound preregistration
  ritual on unrelated tests, which shows the practice is standing rather than
  constructed for this paper.

What this does and does not prove: the hash chain proves ordering within the repository
(design commit is an ancestor of the results commit). It does not prove wall-clock
times against an external clock; the external anchors are the SSRN submission the same
evening and this deposit. The research repository is private (it contains a proprietary
point-in-time panel); the paper's public replication asset is the 99-name notebook
described in the paper.
